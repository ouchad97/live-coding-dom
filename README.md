# Live Coding — JavaScript DOM

## Structure

- `index.html` : structure HTML des 5 cards
- `css/style.css` : styles de départ
- `js/script.js` : espace de travail pour les fonctions JavaScript

## Consigne

Ouvrir `index.html` dans le navigateur, puis compléter `js/script.js` en réalisant les 12 manipulations DOM indiquées dans les commentaires.

Aucune solution JavaScript n'est fournie : les apprenants doivent écrire les fonctions eux-mêmes.
